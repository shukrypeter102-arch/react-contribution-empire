# Salla Product Importer

استيراد آمن للمنتجات إلى متجر Salla كمسودات.

## الإعداد

```bash
npm install
cp .env.example .env
```

## التشغيل

```bash
npm run validate
npm run dry-run
npm run import
```

## ملاحظات
- لا تستخدم صور محمية بحقوق النشر
- الحفاظ على البيانات الشخصية في .env
- ابدأ بـ dry-run قبل الاستيراد الفعلي
